## Optional: 3D Printable Enclosure

The layout is compact enough to fit in a generic 3D-printed case. Recommended interior dimensions:

- **Width:** 80mm+
- **Height:** 50mm+
- **Depth:** 20mm+

Mounting holes for the ESP32 dev board are on the standard 0.9" pitch. The TFT uses an 8-pin SPI header and can be standoff-mounted.
